# 10-Minute Demo Presentation

1. **Problem & Objective (1 min)** — Need to evaluate clinical RAG quality, safety and regression stability.
2. **Framework Architecture (1 min)** — Test Data → Chatbot Executor → Evaluation Engine → Safety Engine → Results → Reports/Dashboard → Regression Suite.
3. **Golden Dataset (1 min)** — 90 scenarios across seven required categories.
4. **Automated Evaluation (2 min)** — Ragas: Answer Relevance, Faithfulness, Context Precision; thresholds 0.80/0.85/0.80.
5. **Safety Testing (1.5 min)** — unsafe medication requests, hallucination, prompt injection, sensitive data exposure.
6. **Defect Reporting (1 min)** — evidence-based AI/safety defects with severity and priority.
7. **Regression & Dashboard (1 min)** — reusable suite and trend-friendly reports.
8. **Final Recommendation (1.5 min)** — show actual measured pass rate, failures and production-readiness recommendation.
